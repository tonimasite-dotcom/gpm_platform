## Восстановление

Инструмент `integrations/workstaff-test-crm/maintenance/verify_cold_rehearsals_stream.py`
получает архив по SSH, расшифровывает на ПК в памяти, сверяет cipher/manifest/object
SHA и передает объекты в новый закрытый каталог старого сервера. Архив, manifest
и объекты на ПК не сохраняются. Существующий ключ остается локальным и не
передается серверу. Проверенный manifest сохраняется только в закрытом каталоге
старого сервера для повторного запуска после разрыва SSH.

Команда полного восстановления после освобождения места:

```text
python -B integrations/workstaff-test-crm/maintenance/verify_cold_rehearsals_stream.py --full-destination /root/gpm-ts-update/cold-restore-20261117-full-01
```

Каталог назначения должен отсутствовать. Инструмент восстанавливает отдельные
файлы вместо hardlink, symlink targets, uid/gid, mode, atime/mtime с наносекундами
и xattrs. Нужны 8,33 GB данных, место для блоков/каталогов, крупнейший объект
239 075 328 байт и резерв 3 GiB: около 12,2 GB свободно. Он не запускает БД и не возвращает файлы
поверх существующих путей. Полный режим проверен на искусственном Linux-наборе
после удаления его искусственных оригиналов. Это не SQL restore свежего TS backup
и не приемка финансового отката.

Удаление подготовлено, но НЕ выполнено. `clean_cold_rehearsals.py` по умолчанию
делает только dry-run. После явного согласования `--apply` повторит все проверки
и удалит только пять точных каталогов. Остальные backup и оригиналы сохраняются.
