# Продолжение GPM: запуск логиста и исполнителя

Прочитай AGENTS.md, .agents/skills/gpm-application/SKILL.md и
PROJECT_HANDOFF_2026-11-24_LAUNCH_ROLES.md. Для деталей опубликованного
тестового обмена — PROJECT_HANDOFF_2026-11-23_SESSION_MINIMAL.md.

Решение владельца от 24.11.2026: сначала запускаем логиста и исполнителя.
Логиста заводим вручную; при регистрации автоматически в CRM не создавать.
Исполнитель должен попадать в CRM при регистрации. Клиента отложить
до готовности всего приложения; пока не создавать его в CRM.

Сейчас работает только отдельная тестовая анкета исполнителя с кодом 123456:
после завершения — связь с единственным рабочим по телефону либо новая
тестовая карточка TS при ближайшем минутном обмене. Это еще не рабочий
аккаунт/JWT GPM и не SMS-регистрация. Следующий шаг — ручная приемка владельцем,
затем рабочая регистрация и сценарии логиста/исполнителя. Не создавать дубли
и не переустанавливать готовое. Клиентов и логистов тестовый обмен не создает.

Зафиксировано только решение, код/данные/серверы не менялись.
Основная CRM и жизненно важные компоненты не затронуты. Основную не менять
без отдельного согласования; схему, аккаунты, авторизацию, аудит, настройки,
backup и инфраструктуру не удалять. Общую модернизацию TS не возобновлять.
Сохранять debt-off/email-защиту TS, снятую панель табеля не возвращать.
Работать через GitHub/Actions без локальных копий на C:; секреты не публиковать.
