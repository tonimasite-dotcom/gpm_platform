# Продолжение TS после проверки изоляции

Прочитай AGENTS.md, навык проекта и [результат от 27.11](PROJECT_HANDOFF_2026-11-27_TS_ISOLATED_PREVIEW.md). Основа ветки 5867c22. Владелец выбрал разделенное пространство TS на сервере закрытого кандидата.

Закрытый вариант nginx под выделенным пользователем TS реально проверен во временном файловом и сетевом пространстве. HTTP/HTTPS дали 200, два API без JWT дали 401. Пробный процесс остановлен, действующие службы TS не перезапускались. Закрытые настройки и квитанция в контуре TS.

Уточнение владельца: на одном сервере должны работать два раздельных проекта. Настройка и закрытая приемка идут только в существующем окружении TS, с ее файлами, базой, конфигурацией и службами. Для публичного доступа владелец выбрал один IP для двух доменов. В закрытом контуре уже есть неактивный виртуальный хост только для ts.workstaffcrm.ru на 443. Подключение этого хоста и перечитывание общего nginx требуют отдельного согласования перед переключением. Тесты и изменения основной CRM запрещены. Окно остановки источника согласовать отдельно. После свежего переноса через MySQL 8.0 в 8.4 сверить 72 таблицы, пройти ручную приемку и включить один обмен. DNS меняет владелец.
