Уже согласованы решения:

- Рекрутеры/admin пока через существующие аккаунты логиста, без новых ролей.
- Гражданство рабочий выбирает один раз, потом меняет только логист. При смене
  сбрасывается подтверждение паспорта. Тип занятости управляется логистом.
- Часы по подтверждённому приходу/уходу, округление вверх до целого часа, не
  ниже минимума заказа; 4 ч 20 мин → 5. Рабочий не завершает вручную; логист
  может отменить JUNK без начисления.
- Оценки: «Справился» +1 (`success`), «Не справился» −2 (`fail`),
  «С нареканиями» −1 (legacy `good`), «Справился хорошо» +2 (`excellent`).
  «Нейтрально» заменено; не возвращать прежние значения.
- Редактирование общих полей заказа синхронизируется в обе стороны. При
  конфликте одного поля **значение приложения главнее**; разные поля объединять.
- Все изменения CRM только `ts.workstaffcrm.ru`. Основную CRM не менять без
  отдельного предварительного явного согласования.
