Это техническая проверка генерации, не полная бизнес-приемка документов:

- В договоре ООО вместо представителя выводится существующее числовое значение
  performer_represented. По форме филиала это nullable текстовое поле, не FK.
  Правильное имя/формулировку не придумывали, реквизиты не исправляли. Требуется
  проверка настройки перед реальным использованием договоров.
- Последний пункт списка приложений отделяется переносом страницы перед
  реквизитами; пагинация требует отдельного решения, текст не обрезан.
- УПД занимает две landscape-страницы. Файлы проверены, полный набор строк,
  длинные/многостраничные услуги и юридическая актуальность формы не приняты.
- UI, document API permissions, отправка почтой/ЭДО, банковские операции,
  оплаченные document allocation workflows и оставшиеся cash/transport/returns/
  выплаты в этом этапе не проверялись. Внешних отправок не было.
