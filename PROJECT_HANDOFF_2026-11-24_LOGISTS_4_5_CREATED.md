# Созданы два логиста GPM с ID #4 и #5

24.11.2026 владелец попросил создать в приложении два конкретных профиля
со снимков и выдать им соответственно #4 и #5.
CRM он заполнит сам. В этом этапе CRM/TS не читались и не менялись.

## Результат

Созданы два новых активных аккаунта с ролью logist, профили с заданными
ФИО/email и форматированным телефоном, корпоративные маршрутизирующие
ID #4/#5 и обычные внутренние коды авторов заявок.
Пароли случайные, сохранены штатными scrypt-хешами.
Проверка паролей перед записью прошла. Старые аккаунты, профили,
корпоративные ID и внутренние коды не менялись:
хеши остальных строк четырех таблиц сравнены внутри транзакции.
Настройки входа/JWT, рабочие заявки и существующие сессии не менялись.
Миграций, удаления схемы или инфраструктуры нет.

ФИО, телефоны, email, логины и пароли в публичные документы не включены.
Связь конкретного профиля с ID есть в запросе владельца и закрытых
операционных данных. Владелец отдельно разрешил временно передать
эти два профиля через GitHub Secrets. Это разрешение относится
к этому конкретному запросу, а не ко всем будущим персональным данным.
Временный секрет после проверки удален, отсутствие проверено.
Другие секреты не менялись.

Новые пароли не выводились в логи: сервер зашифровал их RSA-OAEP для
отдельного ключа владельца. Ключ хранится локально под Windows DPAPI,
личная папка ограничена ACL владельца. Расшифровка и содержимое файла
доступов проверены на его компьютере. Сам файл, ключ, контакты,
закрытые receipts и их локаторы в Git не включены.
Фактический вход владельца через интерфейс остается ручной проверкой.
