## Обязательные ограничения

- Пока работаем только с ts.workstaffcrm.ru. Основную CRM не менять до завершения
  тестов и проверки синхронизации без отдельного явного согласования. Текущее
  исключение разрешает только чтение для сверки: без правок файлов, настроек,
  БД, запуска заданий и переноса данных основной. Основная затронута только чтением;
  ts также только чтением. Жизненно важные компоненты не изменялись.
- Очистка заявок не разрешает удаление таблиц, схемы, кода, аккаунтов, профилей,
  авторизации, приглашений, аудита, конфигурации, секретов, backup и инфраструктуры.
  Для изменения жизненно важных компонентов нужны отдельная задача, перечень
  объектов, оценка последствий, план восстановления и явное согласование.
- Сложные изменения, миграции и операции с рабочими данными требуют отдельного
  согласования объема и последствий. Эта сверка не разрешает автоматический перенос.
