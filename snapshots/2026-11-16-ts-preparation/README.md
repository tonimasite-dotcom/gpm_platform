Получить текущую ветку GitHub и прочитать эти документы. Сохраненный частный

не ко всей CRM и не к финансовому откату. Работающая TS еще не обновлена.
Основная только для разрешенного чтения; все работы и private checks только
на старом сервере TS. Секреты/ключи и копии CRM/БД в этот checkpoint не входят.
