# Полный снимок безопасно остановленного сеанса

Код/инструменты/правила/промпт сохранены в ветке work/ts-resume-2026-11-09.
Данные, приватные отчеты, переписка и изображения находятся только в encrypted
assets GitHub Release `snapshot-20261110-order-parity-stop` этого же репозитория.
Это позволяет получить весь комплект из GitHub без публикации plaintext и без
добавления многогигабайтных бинарных backup в историю каждого git clone.

ARTIFACTS.json содержит точные имена, байты, SHA и ссылки после завершения загрузки.
Для draft Release нужен авторизованный аккаунт с доступом владельца репозитория.
Release не публикует приложение и не является успешным deployment новой CRM.

Скачать комплект в НОВУЮ папку:

```powershell
gh release download snapshot-20261110-order-parity-stop --repo tonimasite-dotcom/gpm_platform --dir .tmp/session-restore-20261110
```

Сначала проверить SHA всех файлов из ARTIFACTS.json. Затем читать
CONTINUE_PROJECT_PROMPT_2026-11-10_SAFE_STOP_FULL_SNAPSHOT.md в корне проекта.
Основной encrypted архив содержит полный private handoff, видимую переписку,
два скриншота, текущий candidate с установленными программными зависимостями,
холодную БД и оба failed datasets, исходники/операторские скрипты/отчеты,
git bundle и предыдущий encrypted архив чата. Три больших TS backup являются
отдельными assets того же комплекта; скачать и проверить нужно ВСЕ assets.

Recovery identity сегодняшнего комплекта хранится отдельно, не в Git и не в
архивах: original-checkout/.tmp/production-backup-20261015/age-identity.txt.
Прежний архив чата требует старого ключа20261109 с Acer; текущий ключ его не открыл.
Не писать содержимое ключей/паролей/кодов в чат или логи.

Для проверки основного архива без извлечения можно использовать
baseline/order-parity/verify_sealed_snapshot.py: нужны --archive, --sha256,
--age, --identity и --report (в приватной папке). Все plaintext остается в памяти,
symlink не активируются. Нельзя восстанавливать архив поверх работающих CRM.
Если сервер и рабочие каталоги на месте, продолжать по сохраненным каталогам,
а не запускать restore/init повторно. Изображения/внутренние отчеты в public Git
не добавлять. Рабочее обновление заявок пока не готово, миграционные проверки
не прошли; точная точка остановки — в private handoff.
