В частной папке есть branch-progress.bundle — изменения ветки после c5d042a.
Для переноса Git на другой компьютер сначала получить базовый commit c5d042a
из репозитория, проверить git bundle verify, затем импортировать bundle в новую
ветку. Не применять его к пользовательской main с незакоммиченными правками.
Существующий worktree и GitHub — основной рабочий источник; bundle резервный.

Сборщик проверяет CRC всех ZIP entries и SHA каждого упакованного файла.
Итоговые размеры/хеши/SHA commit записаны в PACKAGE_VERIFICATION.json рядом
с ZIP, а не в рекурсивно изменяющемся манифесте внутри собственного архива.
Для переноса проекта безопаснее сначала прочитать промпт, затем проверить пути
и локальный manifest. Исторические инструкции в чате не отменяют последние
прямые ограничения владельца, перечисленные в полном PROJECT_SNAPSHOT.
