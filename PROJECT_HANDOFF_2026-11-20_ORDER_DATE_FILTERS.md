# GPM: фильтры дат рабочих и логистов — 20.11.2026

## Опубликованное поведение

- У грузчика выбор «Сегодня / Завтра / Все» по дате выполнения scheduled_at. По последнему уточнению владельца по умолчанию выбрано «Сегодня», «Все» стоит последним. Выбор действует вместе с вкладками «Доступные», «Мои», «История».
- У логиста — кнопка «Дата публикации», период «С даты / По дату» по created_at (та же дата, что в плашке «Опубликовано»). Можно вводить даты или выбирать в календаре, применить, отменить, сбросить. Период сочетается со статусами и очередями оценок. Последний день включен полностью; обратный период не принимается.
- Даты используют тот же локальный часовой пояс, что карточки. Переключение фильтра не перезапрашивает список. Без активного ограничения отсутствующие/некорректные даты остаются; при активном фильтре не считаются попавшими в период. «Все» у рабочего возвращает записи без даты.
- Чаты и клиентские списки не менялись. Настройки чатов владелец явно отложил. Показатели рабочего остаются на главной; ранее убранные дубли «Финансы / Чаты / Профиль» не возвращались. Предыдущую очистку главной владелец подтвердил.
