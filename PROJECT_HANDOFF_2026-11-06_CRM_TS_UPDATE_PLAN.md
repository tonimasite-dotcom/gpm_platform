# GPM: подтвержден объем обновления ts, подготовлен план

## Новое решение владельца

После дневного PDF (`964776f`) владелец подтвердил пять условий: обновить только
ts до актуальной общей функциональности основной, сохранить GPM/редактор ставки/
ограничения логиста, учетные записи/настройки/данные ts; не копировать рабочие
данные/секреты основной; допускается короткая остановка ts. Основную не менять.
Ответы коллег по синхронизации **уже есть**, но оставлены отдельной задачей.
Старое указание «ждем ответов» в дневном PDF/предыдущих handoff теперь историческое.

Подготовлен [CRM_TS_UPDATE_PLAN_2026-11-06.md](CRM_TS_UPDATE_PLAN_2026-11-06.md),
включая этапы пакета/репетиции/применения, сохранения GPM и прав, backup/restore,
проверок и отката. Реестр: [migration-plan.csv](audits/crm-ts-update-plan-2026-11-06/migration-plan.csv).
Это план, а не отчет о выполненном обновлении. Конкретные новые последствия
показать после подготовки пакета и репетиции, не просить повторно пять согласованных условий.

источники наличных/идентификационные ключи; освобождение email удаленных аккаунтов

до запуска заменить его агрегатами, чувствительные значения не логировать.

## Ограничения

- Работа только с ts.workstaffcrm.ru. Основную CRM не менять без отдельного
  явного согласования; разрешено только чтение для сверки. В этом этапе она
  только читалась, ts не менялась. Нельзя писать в основную, запускать ее задания,
  миграции или копировать ее рабочие данные/секреты.
- Очистка заявок не разрешает удаление таблиц, схемы, кода, аккаунтов, профилей,
  авторизации, приглашений, аудита, конфигурации, секретов, backup и инфраструктуры.
  Для изменения жизненно важных компонентов нужны отдельная задача, перечень
  объектов, оценка последствий, план восстановления и явное согласование.
  Жизненно важные компоненты в этом этапе не изменялись. Запрет действует и
  для отката/репетиции: не удалять данные или таблицы ради «чистого восстановления».
