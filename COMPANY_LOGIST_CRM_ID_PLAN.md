# ID логиста Джи Пи Эм для CRM

Работа в подготовке. Владелец согласовал ID только для сотрудников Джи Пи Эм; текущему тестовому логисту — #1.
ID не является номером заявки, телефоном или способом входа.

Пакет: отдельные постоянные последовательные ID сотрудников, отметка в доверенном приглашении при заведении, карточка «Ваш ID для CRM» в профиле, отдельное поле «ID в приложении» в окне отправки TS. Сторонние логисты работают через приложение и ID не получают. Самостоятельно включить себе признак сотрудника нельзя.

Расширение данных GPM — две отдельные таблицы: реестр сотрудников/ID и признаки корпоративных приглашений. Существующие аккаунты, телефоны, пароли, JWT, роли, actor-коды L/C и номера заявок не переписываются. В TS добавляется только поле запроса; схемы и номера CRM сохраняются. Старый протокол отправки по телефону остается совместимым.

Проверить выдачу #1/#2 только сотрудникам, конкуренцию, отзыв без повторного использования ID, запрет выдачи внешним и неактивным аккаунтам, защиту от смены владельца уже отправленной заявки, профиль и отправку TS. До рабочего расширения схемы нужны готовые тесты, проверенный backup и согласованный выпуск. Откат — прежний код/интерфейс, новые таблицы сохранить; прежняя отправка по телефону продолжает работать. Не удалять аккаунты, историю или старые записи.

Основную CRM не менять. TS — только точечная правка интеграции, без общего обновления, scheduler, дебиторки и рассылок. Работать через GitHub/Actions и собственные разрешенные серверы, без локальных копий. Не публиковать ключи, данные сотрудников/заявок, внутренние адреса, пути хранения и частные backup.
