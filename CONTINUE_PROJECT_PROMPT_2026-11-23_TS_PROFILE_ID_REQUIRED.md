Он автоматически подставляется в окно отправки и там не редактируется. Пустой профиль блокирует отправку на сервере, даже при ID или телефоне в запросе. Сервер перечитывает профиль из БД при каждой публикации, включая повторы, и не допускает другого получателя. Варианты с обязательным ручным вводом при каждой отправке или вводом только в окне отправки отменены владельцем.

CRM не создает аккаунты GPM и не выдает ID. Корпоративный ID выдается при регистрации в приложении по доверенному приглашению; сторонний логист приложения не получает ID/карточку. Выдачу #1 не повторять.
