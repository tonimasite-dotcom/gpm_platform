## Изменения

- В API каталога логиста добавлены существующие рейтинг, успешные заказы и срывы.
- Эти показатели показаны в списке «Исполнители» и профиле у логиста.
  Карточки откликов используют тот же формат. Demo-каталог приведен к API.
- Рабочему в профиле, логисту в профиле и блоке оценки доступны правила начисления.
- Перед необратимым сохранением логист видит имя исполнителя, выбранный результат,
  изменение баллов и счетчиков. Отмена диалога не отправляет оценку.
- API заявки возвращает рабочему только его собственную оценку, без автора.
  Клиенту внутренние оценки не передаются. Логист сохраняет доступ к оценкам
  своих заявок. Хранимые оценки и аудит не изменяются фильтрацией ответа.

Формула сохранена: «Справился» +1, «Не справился» -2, «С нареканиями» -1,
«Справился хорошо» +2. Начальный рейтинг 0, отрицательные значения допустимы.
Каждая положительная оценка добавляет один успешный заказ; «Не справился»
добавляет один срыв; «С нареканиями» не меняет счетчики.
Оценивает ответственный логист после выполнения, отдельно каждого назначенного
рабочего. Повторы не начисляют баллы; другая оценка после сохранения отклоняется.
Действующие транзакции и блокировки профиля сохранены.

## Границы

Основную CRM менять только после отдельного явного согласования владельца.
Задача по GPM не разрешает менять CRM. Действующая интеграция ограничена
`ts.workstaffcrm.ru`. В этой задаче ни основная CRM, ни тестовая CRM не затронуты.

Очистка заявок не разрешает удаление таблиц, схемы, кода, аккаунтов, профилей,
авторизации, приглашений, аудита, конфигурации, секретов, backup и инфраструктуры.
Для изменения жизненно важных компонентов нужны отдельная задача, перечень
объектов, оценка последствий, план восстановления и явное согласование.
В этом выпуске нет миграций, очистки или пересчета рабочих данных. Изменяются
только отображение рейтинга и фильтрация ответов API; механизм записи оценок,
авторизация, приглашения, аудит, backup и инфраструктура не изменены.
