# Редактор ставки рабочего — только ts.workstaffcrm.ru

Отдельная форма в «Заказах логиста» меняет **только `workers_cost`**. Адрес и
клиентская ставка остаются в прежней заблокированной форме. Manager request,
роли, permissions, схема БД и другие CRM не изменяются.

Согласовано владельцем 15.10.2026: адрес и клиентскую ставку редактируют
менеджеры; логисты — ставку рабочих. Не разблокировать существующую форму целиком.

API: `PATCH /api/logist_orders/{order}/gpm_worker_rate`, JSON
`workers_cost` + `expected_workers_cost`. Существующие auth/active/branch
middleware дополнены правом `read_logist_orders` и ролью `logist` либо
существующим правом `update_logist_orders`. Ограничения города/владельца
соответствуют списку заказов логиста. Закрытые CRM-заказы защищены; строка
блокируется транзакцией. Одновременное изменение ставки возвращает 409,
повтор того же значения безопасен. Любые посторонние поля, включая адрес,
клиентскую ставку и статус, отклоняются. История фиксирует изменение ставки.

`install-worker-rate.py` без аргументов проверяет ровно известную версию ts,
SHA исходных routes/form, PHP 7.4, отсутствие кэша routes/config и новые сценарии.
Нужны существующие node_modules; `npm install` не запускается.

1. `--prepare`: шифрованная копия прежних routes/form/manifest/dist в
   `/root/gpm-snapshots/20261015-worker-rate-ui/`; отдельная сборка в
   `storage/app/gpm-worker-rate-build-20261015`. Рабочие исходники и assets
   не заменяются. Backend `.env` в сборку не копируется, разрешаются только
   публичные MIX-переменные, используемые frontend.
   После разобранной ошибки можно повторить только частную сборку через
   `--build`; работающие файлы этот режим не меняет. Public path Mix задан
   явно внутри сборки, поскольку она находится вне Laravel webroot.
2. Скачать ciphertext и manifest в закрытое хранилище, проверить SHA,
   расшифровку и наличие файлов. Не публиковать plaintext backup.
3. После успешной сборки `--apply`: новые PHP/Vue и точечные вставки route/form,
   затем новые версионные assets и последним атомарно manifest. Старые assets
   сохраняются для уже открытых вкладок. Существующие файлы assets с другим
   содержимым не перезаписываются. Данные заказов не меняются установщиком.

Установщик одноразовый: если исходники уже изменились или новый редактор
существует, он останавливается для проверки. Повторно не применять.
При ошибке публикации исходники восстанавливаются; старый frontend manifest
остаётся/возвращается. Откат после успешной установки: вернуть исходные
routes/form/manifest из проверенной копии, сохранить новые assets и backup;
новые PHP/Vue удалять только после сверки их хэшей с установленным пакетом.
Откат интерфейса не откатывает последующие пользовательские изменения ставки.

Проверки без Laravel/БД/сети:
`php integrations/workstaff-test-crm/tests/worker_rate_test.php` — 20 сценариев.
Реальную сквозную проверку обмена проводить на **незавершённой** заявке из ts;
005/26 уже завершена в GPM, её не открывать повторно ради теста.
