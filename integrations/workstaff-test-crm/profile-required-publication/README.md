# TS: сохраненный ID обязателен для отправки

Отправитель с ролью логиста или администратора сначала сохраняет ID в своем профиле TS. При каждой отправке сервер заново читает профиль из БД и выбирает только сохраненный ID. ID в запросе не заменяет отсутствующее значение и не меняет получателя; отправка по телефону запрещена. Проверка действует и при повторной отправке уже связанной заявки. Невалидный или неактивный ID по-прежнему отклоняется GPM lookup.

В окне отправки ID автоматически подставляется из профиля и показывается без редактирования. Без него кнопка отключена, есть переход в профиль. Для применения к разрешенному TS после выпуска поля профиля prepare.py готовит только изменения Vue и сервиса запросов; обновленный GpmAppOrderPublisher.php устанавливается отдельно тем же точечным пакетом. Миграций и автоматического заполнения профилей нет. Основная CRM и GPM не меняются.
