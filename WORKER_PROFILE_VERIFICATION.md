# Модерация данных исполнителя

Исполнитель может редактировать собственный профиль, указывать наличие
такелажных ремней и инструментов, а также отправлять на модерацию:

- паспортные данные с фотографией основного разворота;
- заявку на подтверждение самозанятости по ИНН.

Поле Email намеренно отсутствует только в форме профиля исполнителя. Оно не
загружается и не отправляется при сохранении этой формы; поля других ролей не
затрагиваются, а ранее сохранённое серверное значение не стирается.

Заявки хранятся отдельно от публичного профиля в таблице
`gpm_app_worker_verifications`. Фотографии не помещаются в PostgreSQL, Git или
Flutter assets: backend сохраняет их в закрытом каталоге из переменной:

```text
GPM_APP_PRIVATE_UPLOAD_DIR=/root/gpm-private-worker-verifications
```

В production переменная обязательна. Каталог должен находиться вне web root,
быть доступен только service user и включаться в отдельно утверждённые backup,
retention и deletion procedures. Максимальный размер изображения — 8 МБ;
разрешены JPEG и PNG.

Логист видит очередь в своём профиле, может открыть вложение через защищённый
bearer endpoint, подтвердить заявку или отклонить её с причиной. Исполнитель
видит только статус и причину отклонения. Изменение ФИО, даты рождения или
гражданства после отправки паспорта сбрасывает его подтверждение и требует
повторной модерации.

До закрытия правовых P0 допускаются только полностью синтетические документы и
данные. Production deployment этой функции требует отдельного backup БД,
настройки приватного каталога и явного подтверждения владельца.
