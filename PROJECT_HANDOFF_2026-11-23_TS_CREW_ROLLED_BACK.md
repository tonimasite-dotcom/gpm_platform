# Откат последней доработки только CRM/TS

23.11.2026 владелец попросил вернуть последние изменения CRM и онлайн-табеля,
сохранив возможность быстрого возврата. Затем явно уточнил:
«Только в CRM/TS, GPM оставить». Откат выполнен только на TS.
Работа была остановлена по просьбе владельца и продолжена после его сообщения
«Ок, ладно, пока продолжай». Возвращать новую версию без новой просьбы нельзя.

## Рабочее состояние

- TS: восстановлены прежние исходники, веб-ресурсы и конфигурация до установки
  бригадного онлайн-табеля. Вернулась прежняя кнопка назначения бригадира.
- Убраны панель «Онлайн-табель GPM», привязки профилей в этой панели,
  отдельное включение табеля и новый маршрут/обмен этой доработки.
  Прежние функции TS, включая ранее добавленный ID в профиле и правила
  отправки заявок, сохранены.
- Восстановление проверено по хешам исходников и опубликованного JS.
  Новый маршрут отсутствует; TS отвечает HTTP 200, режима обслуживания нет.
- GPM оставлен без изменений: PR #32, merge
  0523f4e0aa540647ac7c1db674e89f8fa0480b95,
  deployment 45190998510 success. JS и health сверены, версия не менялась.
  Таблицы, QR-функция и данные GPM не откатывались.
- Новый перенос табеля и старшего из TS теперь не работает, поскольку
  соответствующий адаптер снят по просьбе владельца. Не считать его активным.

## Сохранено для быстрого возврата

Исходники новой версии доступны в Git по метке
ts-crew-attendance-2026-11-23, указывающей на опубликованный commit PR #32.
До отката на TS дополнительно сохранены готовые веб-ресурсы, девять исходников
и конфигурация новой версии в закрытом серверном снимке. Проверены 343 файла.
Подготовлен return_saved.py: пробная проверка подтвердила готовность
возврата без повторной сборки; режим применения не запускался.
Точные адреса снимка, конфигурация и операционные отчеты в публичный Git не внесены.

Если владелец захочет вернуть доработку, сначала проверить текущие версии GPM/TS
и закрытый forward receipt. Помощник откажется перезаписывать изменившиеся
после отката исходники или конфигурацию. Применение требует новой просьбы владельца.
Три таблицы GPM заново не создавать, PR #32 повторно не выпускать.
Без восстановления адаптера не обещать передачу нового табеля в TS.

## Границы

Основная CRM не затрагивалась. В этом откате менялись только файлы,
конфигурация и веб-ресурсы TS, без миграций и изменений рабочих данных.
API, схема, аккаунты и жизненно важные компоненты GPM оставлены без изменений.
Очистка заявок не разрешает удалять таблицы, аккаунты, авторизацию, аудит,
конфигурации, секреты, backup и инфраструктуру. Основную CRM нельзя менять
без отдельного явного согласования владельца.
