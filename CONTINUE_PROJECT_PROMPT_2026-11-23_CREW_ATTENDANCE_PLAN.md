# Продолжение: бригадные QR-отметки

Прочитать AGENTS.md, навык GPM, PROJECT_HANDOFF_2026-11-23_CREW_ATTENDANCE_PLAN.md
и plans/crew-attendance/PLAN.md. Сверить актуальную main и ветку плана.

Это проект для отдельного согласования объема сложной функции; не считать
таблицы уже созданными или приложение обновленным бригадной логикой.
Подтвержденные решения: QR каждого сканирует старший, клиент сканирует только
старшего, индивидуальные время/геолокация, исключения решает логист, табель
GPM переносится в CRM. Прототип схемы содержит три новые таблицы GPM;
существующие аккаунты, телефоны и финансовые данные не переписывать.

Основную CRM не менять без отдельного согласования; разрешенная сверка только
для чтения. Очистка заявок не разрешает удалять схемы, аккаунты, auth, аудит,
настройки, backup и инфраструктуру. debt-off, деловую почту, scheduler и очереди
TS не включать. GPM и CRM/TS строго разделять, работать через GitHub/Actions,
без исходников и сборок на C:. Закрытые реквизиты и переписку не публиковать.
